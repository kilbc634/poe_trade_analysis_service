# 部位 × 詞綴分佈（哪些屬性在哪個部位拿得到、拿得到多少）

## 腰帶（`accessory.belt`）

### 基底：問生命就是 Leather Belt，沒有第二個答案

`Leather Belt` 的 implicit 是 **`+(25–40) to maximum Life`**（`stat.implicit.stat_3299347043`，mod level 10），是唯一直接送生命的腰帶基底。實測 2026-07-28：任何以「總生命」為門檻的腰帶查詢，**前 20 名清一色 Leather Belt**——這不是取樣偏差，是基底決定的。要別的基底就得放棄那 25–40 免費生命。

### 生命的天花板拆解

一條腰帶的 pseudo 總生命 = **explicit 生命前綴（頂階實測到 +144）+ implicit（≤ +40）+ 力量 ÷ 2**。

| 總生命 | 現實難度 |
|---|---|
| ~180 | 大眾線，單靠一條中高階生命前綴 + implicit 就到 |
| ~195 | 要生命前綴接近頂 + implicit 接近 40 + 一條力量後綴 |
| **200** | **牆**。等於三個來源都得接近滿值，供給斷崖式下降（見 [market.md](market.md)） |
| 219 | 實測全聯盟最高段，只有個位數件 |

### 抗性

三抗是**後綴**，腰帶只有 3 個後綴位，而力量、藥劑類詞綴也搶同一批位子。實務結果：

- **三抗合計 80–95 的件，通常只有 2 條抗性詞綴**（單條 43–48% 的高 roll），第三色是空的。
- **三色齊全（合計 ~100，各 32–34%）反而比 2 條高 roll 貴**——見 market.md 的階梯。
- `+#% to Lightning and Chaos Resistances` 這種混合後綴，pseudo 三抗只計雷抗那一半。
- **後綴位不夠時還有一條路：買「空後綴」的便宜貨自己打工藝抗性**——見 [crafting.md](crafting.md)。

### 詞綴位互斥：生命與三抗齊全搶不到同一件

生命前綴滿 + 力量後綴 + 三色抗性後綴 = 後綴要 4 條，腰帶塞不下。所以「生命 200 且三抗 100」這種需求在市場上是**兩位數 divine 級**，不是加價一點點的事。要三色齊全就得接受生命壓在 ~180。

### 由此得到的部位排序（單件 pseudo 生命上限，稀有裝、req≤75）

**腰帶 ~200 > 頭盔 ~195 > 項鍊 ~170 > 戒指 ~155 > 手套 ~160(抗性一上去就崩)**。

- **手套是六部位裡最弱的生命位**：衝生命型能到 L140，但只要同時要求 R70 以上，在架數立刻掉到個位數（L110/R80 只有 3 件）。配裝時**別指望手套同時出血和抗**，讓它專職其中一項。
- **腰帶依然是生命王**（與本檔上半部的腰帶章節一致），且 L180/R40 有 74 件，是「高血兼帶一點抗」最好拿的部位。
- **戒指是抗性主力**：L110/R70 有 429 件、L135/R60 到 ≤10c 還有 47 件，供給遠比其他部位厚。缺抗優先壓在兩隻戒指上。

### 重跑要快：候選集瘦身（使用者要求 2026-07-28）

聯盟初期便宜裝**分鐘級**被買走，配裝結果常常要重算好幾輪。精確解（每部位 ~120 候選）光是
combine 就要好幾分鐘，重算太慢。**重跑時把每部位的候選數砍到 ~45**（保留 Pareto 前緣的極端點：
血量前 N、火／冰／雷各前 N、性價比前 N），組合數從 183 萬掉到 ~9 萬，**整輪 <1 分鐘**。
代價見 [market.md](market.md) 的實測差距——首次交付用精確解，補件重跑用瘦身版。

## 屬性詞綴：部位有「破格規則」，不是只看基底的屬性對應（使用者教 2026-08-02，已實證）

直覺的對應是 **ES↔智慧、Armour↔力量、Evasion↔敏捷**——基底沒有 evasion 就不該出敏捷詞綴。
這個大方向正確，但**另外存在兩條部位層級的破格規則**：

- **手套：不論基底類型，都可以出敏捷（dex）詞綴。**
- **頭盔：不論基底類型，都可以出智慧（int）詞綴。**
- **胸甲、鞋子沒有這種破格規則**，照基底屬性走。

### 怎麼從 API 分辨「自然詞綴」與「精華硬塞」——看 tier 的數字（2026-08-02 實測）

這條規則在交易站資料上有乾淨的指紋。同樣是 `+# to Dexterity`、同樣是純 ES 底：

| 部位／基底 | 詞綴階級 | es≥該部位高標 + 敏≥45 的在架數 |
|---|---|--:|
| 手套 Warlock Gloves | `of the Blur` **S1**／`of the Wind` **S2**／`of the Phantom` **S3** | **405** |
| 頭盔 Lich's Circlet | 六件**全部 S0**（`of the Essence`／`of the Blur`／`of the Phantom`） | **16** |

**`S0` = 不在該部位的自然詞綴池**（精華等強制手段塞進去的），正常詞綴一律是 `S1`/`S2`/`S3`…。
供給數差 25 倍也印證了這點。實務結論：

- **敏捷缺口可以壓在手套上**，不必全部丟給戒指——這會把戒指的後綴解放出來補抗性。
- **頭盔的敏捷不能當常態供給**（全聯盟只有 16 件，且是精華貨）。真要買也買得到，但別在配裝時假設它存在。
- 這個 `S0` 判別法可以推廣到任何「這條詞綴在這個部位是不是自然出的」的問題。

## 能量護盾（ES）：兩種完全不同的來源，混用會算錯（2026-08-02 實測）

| 部位 | ES 來源 | API 欄位 |
|---|---|---|
| 頭盔、手套（護甲類） | 物品本身的 ES **防具值**（已含該件的區域 flat ES 與 %增加 ES） | `item.extended.es` |
| 戒指、腰帶（飾品） | **全域** `+# to maximum Energy Shield` 詞綴 | 詞綴文字（`extended` 是空的） |

- **護甲類不可以再去解析 `+# to maximum Energy Shield` 詞綴**，那是區域詞綴、已經含在 `extended.es` 裡，兩邊都算就是重複計算。
- **飾品不可以用 `extended.es`**，那個欄位根本不存在，會把每一隻戒指腰帶都算成 0 ES。
- ⚠ **`extended.es` 是「品質 20% 正規化值」，不是物品當下顯示的數字。** 實測四頂頭盔：
  `properties` 顯示 237／211／232／218，`extended.es` 是 284／253／278／262，**剛好各 ×1.2**。
  交易站的 `armour_filters.es` 篩的也是這個正規化值（用 es≥250 撈到的四件，當下 ES 全都 <250），
  所以**篩選與評分口徑一致**。交付時要提醒買家「回來補品質到 20% 才吃得到這個數字」。

### ES 部位天花板（2026-08-02，稀有裝、不設需求等級上限、`securable`）

| 部位 | 條件 | 在架數 |
|---|---|--:|
| 頭盔 | ES 500 = 25、**ES 550 = 3**、ES 600 = 0 | 天花板 ~550 |
| 頭盔 | ES 500＋三抗 70 = 109／ES 470＋三抗 100 = 79／ES 430＋三抗 130 = 30 | |
| 手套 | ES 300 = 170、**ES 340 = 16** | 天花板 ~340 |
| 手套 | ES 300＋三抗 70 = 442／ES 280＋三抗 100 = 199／ES 250＋三抗 130 = 104 | |
| 戒指 | 平擊 ES：ES 45 常見、ES 60 = 40 件、單件最高見到 105 | |
| 腰帶 | ES 80 = 3199、ES 110＋三抗 60 = 604 | 水晶腰帶隱性撐起來的 |

⚠ **價格帶完全不同於純血量配裝**：高 ES 的護甲件很貴。手套 ES≥300＋三抗 70 那 441 件，
**最便宜的 30 件就落在 600–1036c**；頭盔 ES≥500＋三抗 70 最便宜的 30 件落在 1209–2245c。
這與 [market.md](market.md) 記的「1–10c 大宗商品」是兩個世界——**ES 配裝的預算是會咬到的**。

### 腰帶是二選一：水晶腰帶的 ES 隱性 vs 重革腰帶的力量隱性

實測 **`力量 ≥80` 且 `ES ≥70` 的腰帶在架 0 件**（力量 ≥80 單獨有 4896 件、ES ≥80 單獨有 3199 件）。
兩個隱性互斥，而力量與 ES 各自的高階詞綴又都要吃前後綴位。所以配裝時
**力量缺口要嘛壓在腰帶（放棄腰帶的大 ES），要嘛分給戒指／手套**，這是個真的分叉，不要預設。

### 單一元素（火）的供給

`pseudo_total_elemental_resistance` 是**元素盲的**——需求偏食（例：火 129 / 冰 62 / 雷 91）時必須改用
`pseudo_total_fire_resistance` 另開池，否則撈回來的三抗會配錯顏色。≤5c、高生命 + 火抗 ≥40 的在架數：
**戒指 299、腰帶 200、手套 140、頭盔 137、項鍊 127**——單色火抗一點都不稀缺，放心當條件用。
