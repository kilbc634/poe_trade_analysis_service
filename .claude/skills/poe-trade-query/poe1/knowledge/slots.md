# 部位 × 詞綴分佈（哪些屬性在哪個部位拿得到、拿得到多少）

## 腰帶（`accessory.belt`）

### 基底：問生命就是 Leather Belt，沒有第二個答案

`Leather Belt` 的 implicit 是 **`+(25–40) to maximum Life`**（`stat.implicit.stat_3299347043`，mod level 10），是唯一直接送生命的腰帶基底。實測 2026-07-28：任何以「總生命」為門檻的腰帶查詢，**前 20 名清一色 Leather Belt**——這不是取樣偏差，是基底決定的。要別的基底就得放棄那 25–40 免費生命。

### 生命的天花板拆解

一條腰帶的 pseudo 總生命 = **explicit 生命前綴（頂階實測到 +144）+ implicit（≤ +40）+ 力量 ÷ 2**。

| 總生命 | 現實難度 |
|---|---|
| ~180 | 大眾線，單靠一條中高階生命前綴 + implicit 就到 |
| ~195 | 要生命前綴接近頂 + implicit 接近 40 + 一條力量後綴 |
| **200** | **牆**。等於三個來源都得接近滿值，供給斷崖式下降（見 [market.md](market.md)） |
| 219 | 實測全聯盟最高段，只有個位數件 |

### 抗性

三抗是**後綴**，腰帶只有 3 個後綴位，而力量、藥劑類詞綴也搶同一批位子。實務結果：

- **三抗合計 80–95 的件，通常只有 2 條抗性詞綴**（單條 43–48% 的高 roll），第三色是空的。
- **三色齊全（合計 ~100，各 32–34%）反而比 2 條高 roll 貴**——見 market.md 的階梯。
- `+#% to Lightning and Chaos Resistances` 這種混合後綴，pseudo 三抗只計雷抗那一半。

### 詞綴位互斥：生命與三抗齊全搶不到同一件

生命前綴滿 + 力量後綴 + 三色抗性後綴 = 後綴要 4 條，腰帶塞不下。所以「生命 200 且三抗 100」這種需求在市場上是**兩位數 divine 級**，不是加價一點點的事。要三色齊全就得接受生命壓在 ~180。

### 由此得到的部位排序（單件 pseudo 生命上限，稀有裝、req≤75）

**腰帶 ~200 > 頭盔 ~195 > 項鍊 ~170 > 戒指 ~155 > 手套 ~160(抗性一上去就崩)**。

- **手套是六部位裡最弱的生命位**：衝生命型能到 L140，但只要同時要求 R70 以上，在架數立刻掉到個位數（L110/R80 只有 3 件）。配裝時**別指望手套同時出血和抗**，讓它專職其中一項。
- **腰帶依然是生命王**（與本檔上半部的腰帶章節一致），且 L180/R40 有 74 件，是「高血兼帶一點抗」最好拿的部位。
- **戒指是抗性主力**：L110/R70 有 429 件、L135/R60 到 ≤10c 還有 47 件，供給遠比其他部位厚。缺抗優先壓在兩隻戒指上。

### 重跑要快：候選集瘦身（使用者要求 2026-07-28）

聯盟初期便宜裝**分鐘級**被買走，配裝結果常常要重算好幾輪。精確解（每部位 ~120 候選）光是
combine 就要好幾分鐘，重算太慢。**重跑時把每部位的候選數砍到 ~45**（保留 Pareto 前緣的極端點：
血量前 N、火／冰／雷各前 N、性價比前 N），組合數從 183 萬掉到 ~9 萬，**整輪 <1 分鐘**。
代價見 [market.md](market.md) 的實測差距——首次交付用精確解，補件重跑用瘦身版。

### 單一元素（火）的供給

`pseudo_total_elemental_resistance` 是**元素盲的**——需求偏食（例：火 129 / 冰 62 / 雷 91）時必須改用
`pseudo_total_fire_resistance` 另開池，否則撈回來的三抗會配錯顏色。≤5c、高生命 + 火抗 ≥40 的在架數：
**戒指 299、腰帶 200、手套 140、頭盔 137、項鍊 127**——單色火抗一點都不稀缺，放心當條件用。
