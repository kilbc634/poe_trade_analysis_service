# POE1 knowledge base index

目前有匯率來源、**六個部位的生命×三抗天花板**（頭盔／手套／項鍊／戒指／腰帶，2026-07-28 實測）、

以及**花園工藝把單元素抗性換色／重骰**這個高價裝備專用手法。

⚠ **[releveling.md](releveling.md)（重練）是獨立的一題，與上面這些 CP 值配裝知識無關**——
目標函數是「最小化通關時間」而非「預算內最大化分數」，硬約束是需求等級而非價格，
而且沒有配裝空間（社群定型公式）。碰到「重練／練小號／twink」先讀那份，不要套求解器那一套。
