# 花園工藝（Horticrafting）— 單元素抗性可以「換色」與「重骰」

與 [crafting.md](crafting.md) 的**工藝台（craft bench）是兩個不同的工作台**，規則不共用：
工藝台是「在空後綴上**加一條新的**詞綴」，園藝是「把**既有的一條**詞綴改成另一種」。
兩者可以疊用（同一件上一條工藝抗性 + 把某條原生抗性轉色），互不佔用對方的名額。

## 配方：3 種元素的所有有序配對，共 6 條

工作台實查（過濾字串 `res`）：

| 配方 | 消耗 |
|---|---|
| 冰 → 火 | 500 **紫**（Wild） |
| 雷 → 火 | 500 **紫**（Wild） |
| 火 → 冰 | 500 **黃**（Vivid） |
| 雷 → 冰 | 500 **黃**（Vivid） |
| 火 → 雷 | 500 **藍**（Primal） |
| 冰 → 雷 | 500 **藍**（Primal） |

**消耗的顏色由「轉換後」的元素決定**——換成火吃紫、換成冰吃黃、換成雷吃藍。

三色的正式名稱（使用者提供並逐格確認，可直接拿去交易站查匯率。
⚠ **Wild 的圖示在截圖裡看起來偏紅／洋紅，不要誤判成另一種顏色**）：

| 顏色 | 名稱 |
|---|---|
| 黃 | `Vivid Crystallised Lifeforce` |
| 藍 | `Primal Crystallised Lifeforce` |
| 紫 | `Wild Crystallised Lifeforce` |

**成本：500 lifeforce ≈ 50–70c**（隨市場浮動，**黃色 Vivid 通常較貴 → 轉成冰是最貴的方向**）。
每按一次就是 50–70c，所以**這是高價值裝備專用的手法**。

## 規則

- 詞綴文字是 *"into a **similar-tier** modifier"*：**tier 不變，但 roll 值重骰。**
- **只吃單元素抗性詞綴。** 複合抗性（火冰、雷混…）與純混沌抗**不適用**。
- **次數無限**（只受 lifeforce 存量限制）。
- **只動那一條詞綴**，其他詞綴完全不受影響——這是它相對神聖石的最大優勢。
- **腐化（corrupted）裝備不能做園藝轉換**（與工藝台一樣被腐化封死）。
- 工藝台打上去的抗性**可以**被轉，但**不值得**——工藝本來就能近乎零成本洗掉重上。
  換句話說：**園藝只該用在原生（native）詞綴上。**
- **轉換是「平移」不是「升級」**：tier 鎖死，T5 冰抗只會變成 T5 火抗。
  所以顏色是不是硬約束**要看當下情況**——它救得了「顏色錯」，救不了「階級低」。

## 三種用法（使用者教，2026-09-05）

### 1. 來回轉換 = 只針對一條詞綴的神聖石

有件 T1 火抗 `+46% to Fire Resistance`（該階範圍 46–48），剛好差 2% 滿抗：
**火 → 雷 → 火** 來回幾次，tier 不變、roll 重骰，就有機會洗到 48。
神聖石效果相同，但**神聖石會動到全部詞綴**；園藝**保證只動這一條**，通常也更划算。

### 2. 溢出抗性換色

冰抗總和 120、最大抗性只有 75 → **45 點是浪費的**。
把某件上的 `+42% 冰抗` 轉成火或雷，等於憑空生出 42 點有效抗性，
**減緩其他部位的配抗壓力**（那些後綴位就能改去拿生命／傷害）。

### 3. 手套「神廟詞」連傷害類型一起轉

手套上有一類複合詞綴（俗稱**神廟詞**），**傷害 + 抗性算成一條**詞綴：

| 詞綴 | 元素 |
|---|---|
| `# to # added Fire Damage against Burning Enemies` / `+#% to Fire Resistance` | 火 |
| `#% increased Damage with Hits against Chilled Enemies` / `+#% to Cold Resistance` | 冰 |
| `#% increased Critical Strike Chance against Shocked Enemies` / `+#% to Lightning Resistance` | 雷 |

因為它帶單元素抗性，**照樣適用園藝轉換**，而且**轉抗性顏色時傷害那一半也跟著改**。
用途：買到便宜的「錯色」神廟手套，轉成自己流派要的傷害類型。

## 對搜尋／配裝的影響

- **高預算部位的單元素抗性顏色是可以買的**（~50–70c/次）。當某部位預算遠高於 60c 時，
  單元素抗性可以當成**顏色不拘**，改用 `pseudo_total_elemental_resistance` 開池，
  供給遠比死鎖單色厚。⚠ [slots.md](slots.md) 那條「pseudo 三抗是元素盲的、偏食需求必須分色開池」
  的警告**只適用於不打算轉換的情況**；高價位部位可以放寬。
- **估值要用該 tier 的中位數，不是掛單上的 roll**——轉換後會重骰。
  人工估價用中位數就夠；腳本可以算得更準，而且**成本是封閉解、不增加計算負擔**（見下節）。
- **便宜件不要套這招**：≤10c 的貨，一次轉換就貴過物件本身。
- 複合抗性詞綴（火冰、雷混）**不能轉**，所以它們的顏色是死的——這反過來讓
  「單元素 vs 複合」的取捨多了一個維度：單元素貴一點但顏色可改，複合便宜但鎖死。

## 洗 roll 的期望成本（封閉解，可直接進求解器）

要**維持同一種顏色**洗 roll，必須「轉出去再轉回來」＝**一次嘗試 = 2 次轉換**，
而且**兩次吃不同顏色的 lifeforce**（例：火 → 雷吃藍、雷 → 火吃紫，
所以一輪火抗重骰 = 500 藍 + 500 紫）。

每次重骰是在該 tier 範圍內重新抽（**假設均勻分布，未實測**），
而且**不滿意就繼續按**，所以這不是「取 n 次最大值」而是幾何分布：

```
期望嘗試次數 = 1 / P(roll ≥ 目標)
期望成本     = 期望嘗試次數 × (500 顆 A 色 + 500 顆 B 色 的市價)
```

**實例**：T1 火抗範圍 46–48（3 個整數值），現有 46、想要 48。
`P = 1/3` → 期望 3 輪 → 3 × (500 藍 + 500 紫) ≈ **300–420c**，買到的是 **+2% 火抗**。

這個數字本身就是結論：**洗 roll 只在「差最後 1–2 點就滿抗、且該部位本來就值數百 c」時才成立**。
**換色**（單次轉換、接受重骰後的值）才是常態用法。
